# Development Control Plane Embed

- Role: MBMApps interactive proof-of-work showing multi-repository orchestration, Decision Intelligence, Design Intelligence, execution governance, and validation.
- Source concept: user-authored MBMApps development control plane and ripple simulator.
- Interaction: select a change event and watch the system identify affected, retained, and blocked work across reasoning layers and repositories.
- Motion: deliberately slow cinematic propagation with route drawing, traveling particles, spring emphasis, and synchronized execution trace.
- Product boundary: this is an explanatory simulation. It does not claim to operate production repositories, approve real changes, or replace repository-specific authority.
- Integration: bundled as a self-contained static document and loaded through a sandboxed iframe at /control-plane.
