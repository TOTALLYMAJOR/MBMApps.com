# Cognitive Strategy Utility

Open `index.html` directly in a browser.

Features:
- Paste arbitrary context
- Add goal and constraints
- Select among 42 reasoning/agentic strategies
- Search and filter categories
- Configure evidence policy and output depth
- Preserve assumptions, unknowns, falsifiers, dissent, human gates, and bounded execution
- Compile a downstream prompt
- Copy/export JSON configuration
- LocalStorage persistence
- No network requests
- Mobile responsive
