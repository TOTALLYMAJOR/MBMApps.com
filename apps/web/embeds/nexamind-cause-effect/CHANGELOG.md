# Cause-and-Effect Layer

## v2.0

- Added explicit fact-to-stage causal routing.
- Added live propagation when discount, contract length, deal value, evidence coverage, or human-approval requirements change.
- Added before/after metric deltas.
- Added authority pass/review state.
- Added recommendation transitions.
- Added dynamic insertion of the Act stage when the permitted action changes.
- Added Evidence Coverage as a first-class scenario fact.
- Added stress-test presets for high discount, thin evidence, short contract, and a safer case.
- Added baseline rebasing so each experiment can start from a known analyzed state.
- Added reduced-motion behavior and responsive stacked layout.
