## Challenge

Regional managers had no shared system for pipeline and quote outcomes. Leadership reviewed stale weekly exports.

## Approach

We implemented a central dashboard with role-aware access, typed API contracts, and telemetry events for usage patterns.

## Result

The operations team moved from retrospective reporting to proactive decision-making. Managers now detect underperforming segments in the same day.
